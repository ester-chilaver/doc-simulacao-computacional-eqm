O Projeto

O que nos trouxe até aqui

Experiências de quase-morte são descritas com uma consistência que intriga: uma luz intensa e centralizada, escuridão progressiva ao redor, a sensação inconfundível de um túnel. O fenômeno é amplamente documentado. A neurobiologia por trás dele, ainda aberta.

Foi tentando entender o que seria necessário para simular esse processo que este projeto nasceu. Quais ferramentas matemáticas descrevem como moléculas se difundem pelo tecido neural? Como modelar numericamente a dinâmica de populações de neurônios? O que acontece, em equações, quando o córtex visual é privado de oxigênio e glicose?

Essas perguntas não têm resposta curta — e algumas permanecem genuinamente em aberto. A luz surge quando a falência metabólica atinge primeiro a retina? Primeiro o córtex? Qualquer uma das duas sequências produziria o mesmo efeito perceptivo? Simular esse processo é uma das formas de investigá-las. Cada módulo constrói uma peça do instrumental necessário para isso. Juntos, eles formam o caminho completo até uma simulação real.
