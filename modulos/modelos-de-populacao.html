01 — A Função de Ativação

A Função de Ativação

Uma população de neurônios recebe input sináptico e responde disparando. Precisamos de uma função que faça essa conversão: entra o input total I, sai a taxa de disparo média da população. E essa função não é uma reta.

A razão é mecânica. Cada neurônio da população tem seu próprio limiar de disparo, ligeiramente diferente do vizinho. Com input baixo, praticamente nenhum neurônio alcança o próprio limiar, e a população fica quase muda. Conforme o input cresce, uma fração cada vez maior da população cruza seu limiar individual — e a taxa média sobe rápido. Quando quase todos já estão disparando, o período refratário entra em cena: cada neurônio precisa de um intervalo mínimo entre disparos, então existe um teto físico de disparos por segundo. A curva achata.

Ou seja: a curva que procuramos é, essencialmente, a distribuição acumulada dos limiares individuais da população — e é por isso que ela tem forma de S. Três propriedades resumem o que ela precisa ter:

1. Abaixo de um limiar θ, a população quase não dispara — poucos neurônios cruzaram o próprio limiar
2. Acima de um certo ponto, a taxa satura — o período refratário impõe um teto de disparos por segundo
3. No meio, uma zona de sensibilidade, onde pequenas mudanças de input geram mudanças grandes na taxa de disparo

Primeiro, a sigmoide no estado puro

A curva com essa forma já existe em matemática, muito antes de qualquer neurônio: é a função logística, ou sigmoide. Na versão mais nua possível, ela é só isto:

σ(x) = 1 / (1 + e−x)
x → −∞ σ tende a 0
x → +∞ σ tende a 1
x = 0 σ vale exatamente 0.5 — é o ponto médio, e onde a curva é mais íngreme

Nessa forma pura ela não tem controle nenhum: a virada acontece sempre em x=0, sempre com a mesma inclinação. Para usá-la, precisamos de dois ajustes — e ambos são feitos trocando o que entra no lugar do x:

σ(a(I − θ)) = 1 / (1 + e−a(I−θ))
θ Desloca a virada: em vez de acontecer em 0, acontece em I = θ
a Controla a inclinação: a alto deixa a virada quase um degrau; a baixo espalha a transição

O que precisa mudar para o nosso modelo

Olhe o valor de σ em I = 0 na simulação acima: ele não é zero. Com os valores padrão, sobra algo em torno de 0.03. E isso é um problema biológico concreto: significaria que a população continua disparando mesmo sem receber input nenhum. Não é o que queremos — sem estímulo, a taxa tem que ser zero.

Quanto exatamente sobra? Basta avaliar a fórmula em I = 0. O expoente −a(I−θ) vira −a(0−θ) = aθ, então:

σ(a(0 − θ)) = 1 / (1 + eaθ)
Esse é o resíduo — uma constante que depende só de a e θ, e não de I.

Como é uma constante, a correção é direta: subtraia exatamente esse valor da curva inteira. É essa — e só essa — a diferença entre a sigmoide de livro-texto e a função de ativação que Wilson e Cowan usam:

F(I) = 1/(1 + e−a(I−θ)) − 1/(1 + eaθ)
F(I) Taxa de disparo média da população
1º termo A sigmoide parametrizada que acabamos de montar
2º termo O resíduo constante, subtraído para ancorar F(0) = 0
♦️
A correção é exata, não aproximada

O segundo termo não foi escolhido por tentativa e erro: ele é, por construção, idêntico ao valor que o primeiro termo assume em I = 0. Por isso F(0) = 0 exatamente, para qualquer a e θ que você escolher — não é uma aproximação que funciona só em certos valores.

Uma consequência secundária: como a curva inteira desceu um pouquinho, a saturação no topo também não chega mais a 1 — ela para em 1 − resíduo. Com a = 1.2 e θ = 2.8, isso dá ≈ 0.966. Compare os dois simuladores e veja a curva inteira deslizar para baixo.

02 — O Modelo

As Equações de Wilson-Cowan

O córtex não tem um tipo só de neurônio. Cerca de 80% são excitatórios — quando disparam, aumentam a chance de seus alvos dispararem. Os outros 20% são inibitórios — quando disparam, reduzem essa chance. Wilson e Cowan (1972) perceberam que dá para descrever uma região cortical inteira acompanhando apenas duas taxas médias: r_E, da população excitatória, e r_I, da inibitória. Cada uma tem sua própria constante de tempo τ, e as duas se influenciam por quatro pesos sinápticos.

🧠
Wilson-Cowan (1972)

Wilson-Cowan foi proposto em 1972 e permanece como o modelo de referência para dinâmica de populações neurais. Ele aparece em modelos de córtex visual, gânglios da base, cerebelo e ritmos EEG. Aprender a intuição deste modelo é aprender a linguagem da neurociência computacional.

τ_E · dr_E/dt = −r_E + F_E(w_EE·r_E − w_EI·r_I + Iext,E)
τ_I · dr_I/dt = −r_I + F_I(w_IE·r_E − w_II·r_I + Iext,I)
τ_E, τ_I Constantes de tempo — controlam quão rápido cada população responde
w_XY Peso sináptico de Y → X (e.g. w_EI = influência de I sobre E)
I_ext Input externo — estímulo sensorial ou corrente injetada
F_E, F_I Funções de ativação sigmodais (seção anterior)

Os quatro pesos formam a matriz de conectividade, e é ela que governa toda a dinâmica: w_EE mede o quanto a população excitatória se realimenta; w_EI, o quanto a inibição segura a excitação; w_IE, o quanto a excitação recruta a inibição; e w_II, o quanto os inibitórios inibem uns aos outros. Cada peso é uma seta no circuito, e cada seta é uma célula da matriz:

ponta de seta = excitatório  ·  barra em T = inibitório

03 — O Espaço dos Comportamentos

Ponto Fixo, Ciclo Limite e o Plano de Fase

O que a simulação anterior mostrou tem um nome formal. Quando o sistema converge para um estado constante, chamamos de ponto fixo estável. Quando oscila indefinidamente, chamamos de ciclo limite. O plano de fase — o gráfico de r_E × r_I — é a ferramenta que deixa esses comportamentos visualmente evidentes.

Regime 01
Ponto Fixo Estável
Atividade constante após transiente inicial. Balanço E-I moderado — a inibição é suficiente para estabilizar a excitação.
Atividade tônica — estado de repouso ativo
Regime 02
Ciclo Limite (Oscilação)
Atividade rítmica persistente. Feedback E-I forte com atrasos temporais — excitação recorre antes que a inibição se dissipe.
Ritmos neurais — alfa, beta, gama

Nullclines e Ponto Fixo

A nullcline de r_E é o conjunto de pontos (r_E, r_I) onde dr_E/dt = 0 — a população excitatória não está mudando. A nullcline de r_I define onde dr_I/dt = 0. A intersecção das duas nullclines é o ponto fixo. Se a trajetória, em vez de convergir para esse ponto, passa ao redor dele indefinidamente, o sistema está num ciclo limite.

Bifurcação de Hopf

Quando os parâmetros cruzam um limiar crítico, o ponto fixo perde estabilidade e surge uma órbita ao seu redor. Esse momento é a bifurcação de Hopf. Biologicamente: é o mecanismo que gera ritmos cerebrais quando um estímulo sensorial aumenta progressivamente.

No plano de fase, isso se manifesta como a trajetória deixando de espiralar em direção ao ponto fixo e passando a orbitar ao redor dele em ciclo fechado.

🩸
Isso não é só matemática de parâmetro — é isquemia

Até agora giramos I_ext livremente pra "descobrir" os três regimes. Mas no córtex de verdade ninguém gira esse botão — I_ext é sustentado pelo fluxo sanguíneo trazendo oxigênio e glicose até a população, pela mesma rede capilar cuja difusão vimos na Escala 02 do Módulo 01.

Isso significa que o diagrama acima também pode ser lido da direita para a esquerda, como o filme de uma isquemia progredindo: conforme o suprimento metabólico despenca, I_ext cai junto, e a população atravessa as mesmas fronteiras na ordem inversa — sai da saturação, entra no ciclo limite (oscilando cada vez mais devagar), e finalmente cruza de volta para o ponto fixo de baixa atividade em I < 0.57. Esse ponto fixo não é "repouso" — é o destino de uma população depois que a falência metabólica cruzou a bifurcação.

05 — Preparando o Salto

Um Ponto Não Faz um Córtex

Tudo o que construímos até aqui — a função de ativação, as equações acopladas, o plano de fase, a bifurcação — descreve uma única população, um ponto (r_E, r_I) só. Mas V1, o córtex visual primário, não é um ponto: são milhões de colunas corticais repetindo essa mesma dinâmica local, lado a lado, cobrindo milímetros de tecido.

A pergunta natural é: e se, em vez de um Wilson-Cowan, tivéssemos uma fileira de N cópias independentes, cada uma recebendo seu próprio I_ext? Cada ponto ainda obedeceria exatamente as mesmas equações — e o mesmo diagrama de bifurcação da seção anterior — só que agora cada um vive seu próprio regime, isoladamente, sem saber o que acontece ao lado.

🧩
A peça que falta já está com a gente desde o Módulo 01

É exatamente aí que entra o termo D∇²A que carregamos desde o Movimento Browniano: no Módulo 04, vamos religar esses pontos, deixando a atividade "vazar" de um pra outro via difusão — a mesma equação de Fourier e Einstein, agora espalhando r_E e r_I pelo tecido cortical em vez de calor ou probabilidade. O Laplaciano que implementamos no Módulo 02 é literalmente a ferramenta que vai suavizar essas transições bruscas entre colunas vizinhas.

Tem uma segunda pergunta em aberto: de onde vem o I_ext de cada ponto? Numa simulação abstrata, é só um parâmetro que giramos num slider. No córtex visual de verdade, cada coluna cortical recebe I_ext vindo de um pedacinho específico do campo visual — essa correspondência tem nome.

👁️
Retinotopia — o mapa que o córtex desenha da retina

Cada neurônio de V1 responde principalmente a estímulos vindos de uma pequena região do campo visual — seu "campo receptivo". Neurônios vizinhos na retina projetam para neurônios vizinhos no córtex, formando um mapa contínuo: a retinotopia.

Esse mapa não é uniforme: a região central da visão (a fóvea) ocupa uma fatia desproporcionalmente grande do córtex — a magnificação cortical. Quanto mais periférico o campo visual, menos território cortical ele recebe, numa relação aproximadamente logarítmica. É essa geometria, invertida, que vamos usar no Módulo 04 para entender por que um colapso que começa no centro do córtex aparece, na percepção, como um túnel se fechando a partir das bordas do campo visual.

python — funcao_ativacao 
import numpy as np

def F(I, a, theta):
    """Função de ativação sigmoidal com correção F(0)=0.

    Args:
        I     : input sináptico total
        a     : ganho (inclinação na região de transição)
        theta : limiar (inflection point)
    Returns:
        taxa de disparo média em [0, 1)
    """
    return (1 / (1 + np.exp(-a * (I - theta)))) \
         - (1 / (1 + np.exp(a * theta)))
python — wilson_cowan_derivatives 
    def derivatives(self, rE, rI):
        """Calcula drE/dt e drI/dt para o estado (rE, rI)."""
        p = self.params
        input_E = p['wEE'] * rE - p['wEI'] * rI + p['Ie']
        input_I = p['wIE'] * rE - p['wII'] * rI + p['Ii']
        drE = (-rE + F(input_E, p['aE'], p['thE'])) / p['tauE']
        drI = (-rI + F(input_I, p['aI'], p['thI'])) / p['tauI']
        return drE, drI
python — wilson_cowan_rk4_step 
    def step_rk4(self, dt=0.1):
        """Avança o estado em um passo RK4 de tamanho dt."""
        k1e, k1i = self.derivatives(self.rE,                self.rI)
        k2e, k2i = self.derivatives(self.rE + dt/2 * k1e, self.rI + dt/2 * k1i)
        k3e, k3i = self.derivatives(self.rE + dt/2 * k2e, self.rI + dt/2 * k2i)
        k4e, k4i = self.derivatives(self.rE + dt     * k3e, self.rI + dt     * k3i)
        self.rE += (dt / 6) * (k1e + 2*k2e + 2*k3e + k4e)
        self.rI += (dt / 6) * (k1i + 2*k2i + 2*k3i + k4i)
        self.rE = np.clip(self.rE, 0.0, 1.0)
        self.rI = np.clip(self.rI, 0.0, 1.0)
python — calcular_nullcline 
def calcular_nullcline_E(params, n_pts=200):
    """Retorna pontos (rE, rI) onde drE/dt = 0 (nullcline de E)."""
    p = params
    rI_vals = np.linspace(0, 1, n_pts)
    rE_pts  = []

    for rI in rI_vals:
        # bissecção: encontra rE em [0,1] tal que -rE + F(wEE*rE - wEI*rI + Ie) = 0
        lo, hi = 0.0, 1.0
        for _ in range(50):
            mid = (lo + hi) / 2
            g   = -mid + F(p['wEE']*mid - p['wEI']*rI + p['Ie'], p['aE'], p['thE'])
            if g > 0: lo = mid
            else:     hi = mid
        rE_pts.append((lo + hi) / 2)

    return np.array(rE_pts), rI_vals
