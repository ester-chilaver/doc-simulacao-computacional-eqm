01 — A Peça Fundamental

Função de Ativação: Do Input à Taxa de Disparo

Para modelar uma população de neurônios, precisamos de uma função que converta o input sináptico total recebido em taxa de disparo média. Essa função deve ter três propriedades biológicas: (1) abaixo de um limiar θ, a população quase não dispara; (2) acima de um nível de saturação, o período refratário limita a taxa máxima; (3) entre os dois, há uma zona de sensibilidade controlada pelo ganho a. A curva sigmoidal captura tudo isso.

F(I) = 1/(1 + e−a(I−θ)) − 1/(1 + eaθ)
F(I) Taxa de disparo média da população, normalizada em [0, 1]
a Ganho — controla a inclinação da curva na zona de sensibilidade
θ Limiar — o input em que a curva tem sua maior taxa de mudança
−1/(1+eaθ) Garante que F(0) = 0: sem input, sem disparo
♦️
Por que subtrair o segundo termo?

Sem o segundo termo, F(0) ≠ 0 — a população dispararia mesmo sem input. O segundo termo desloca a curva para que o ponto de repouso (sem input) seja exatamente zero. Biologicamente: sem estimulação, a taxa de disparo espontânea é mínima.

import numpy as np

def F(I, a, theta):
    """Função de ativação sigmoidal corrigida: F(0) = 0."""
    return (1 / (1 + np.exp(-a * (I - theta))) \
         - (1 / (1 + np.exp(a * theta)))
02 — O Sistema Central

Wilson-Cowan: Excitação e Inibição em Equilíbrio

Imagine dois grupos de pessoas numa reunião: um grupo que amplifica ideias (excitatório, E) e outro que pondera e freia (inibitório, I). O comportamento coletivo emerge da tensão dinâmica entre eles. O modelo Wilson-Cowan (1972) formaliza exatamente isso para populações neurais: duas variáveis acopladas, r_E e r_I, cada uma com sua própria constante de tempo τ, conectadas por quatro pesos sinápticos.

🧠
Wilson-Cowan (1972)

Wilson-Cowan foi proposto em 1972 e permanece como o modelo de referência para dinâmica de populações neurais. Ele aparece em modelos de córtex visual, gânglios da base, cerebelo e ritmos EEG. Aprender a intuição deste modelo é aprender a linguagem da neurociência computacional.

τ_E · dr_E/dt = −r_E + F_E(w_EE·r_E − w_EI·r_I + Iext,E)
τ_I · dr_I/dt = −r_I + F_I(w_IE·r_E − w_II·r_I + Iext,I)
τ_E, τ_I Constantes de tempo — controlam quão rápido cada população responde
w_XY Peso sináptico de Y → X (e.g. w_EI = influência de I sobre E)
I_ext Input externo — estímulo sensorial ou corrente injetada
F_E, F_I Funções de ativação sigmodais (seção anterior)

python — wilson_cowan_rk4 
class WilsonCowanRK4:
    def __init__(self, params):
        self.p = params
        self.rE = 0.1
        self.rI = 0.1

    def F(self, I, a, theta):
        return 1/(1 + np.exp(-a*(I - theta))) - 1/(1 + np.exp(a*theta))

    def derivatives(self, rE, rI):
        p = self.p
        IE = p['wEE']*rE - p['wEI']*rI + p['Ie']
        II = p['wIE']*rE - p['wII']*rI + p['Ii']
        drE = (-rE + self.F(IE, p['aE'], p['thE'])) / p['tauE']
        drI = (-rI + self.F(II, p['aI'], p['thI'])) / p['tauI']
        return drE, drI

    def step_rk4(self, dt=0.1):
        k1e, k1i = self.derivatives(self.rE,            self.rI)
        k2e, k2i = self.derivatives(self.rE + dt/2*k1e, self.rI + dt/2*k1i)
        k3e, k3i = self.derivatives(self.rE + dt/2*k2e, self.rI + dt/2*k2i)
        k4e, k4i = self.derivatives(self.rE + dt*k3e,    self.rI + dt*k3i)
        self.rE += (dt/6) * (k1e + 2*k2e + 2*k3e + k4e)
        self.rI += (dt/6) * (k1i + 2*k2i + 2*k3i + k4i)
        self.rE = np.clip(self.rE, 0, 1)
        self.rI = np.clip(self.rI, 0, 1)
03 — O Espaço dos Comportamentos

Ponto Fixo, Ciclo Limite e o Plano de Fase

O que a simulação anterior mostrou tem um nome formal. Quando o sistema converge para um estado constante, chamamos de ponto fixo estável. Quando oscila indefinidamente, chamamos de ciclo limite. O plano de fase — o gráfico de r_E × r_I — é a ferramenta que deixa esses comportamentos visualmente evidentes.

Regime 01
Ponto Fixo Estável
Atividade constante após transiente inicial. Balanço E-I moderado — a inibição é suficiente para estabilizar a excitação.
Atividade tônica — estado de repouso ativo
Regime 02
Ciclo Limite (Oscilação)
Atividade rítmica persistente. Feedback E-I forte com atrasos temporais — excitação recorre antes que a inibição se dissipe.
Ritmos neurais — alfa, beta, gama

Nullclines e Ponto Fixo

A nullcline de r_E é o conjunto de pontos (r_E, r_I) onde dr_E/dt = 0 — a população excitatória não está mudando. A nullcline de r_I define onde dr_I/dt = 0. A intersecção das duas nullclines é o ponto fixo. Se a trajetória, em vez de convergir para esse ponto, passa ao redor dele indefinidamente, o sistema está num ciclo limite.

Bifurcação de Hopf

Quando os parâmetros cruzam um limiar crítico, o ponto fixo perde estabilidade e surge uma órbita ao seu redor. Esse momento é a bifurcação de Hopf. Biologicamente: é o mecanismo que gera ritmos cerebrais quando um estímulo sensorial aumenta progressivamente.

No plano de fase, isso se manifesta como a trajetória deixando de espiralar em direção ao ponto fixo e passando a orbitar ao redor dele em ciclo fechado.

def F(I, a, theta):
    """Função de ativação sigmoidal com correção F(0)=0.

    Args:

        a     : ganho (inclinação na região de transição)
        theta : limiar (inflection point)
    Returns:
        taxa de disparo média em [0, 1)
    """
    return (1 / (1 + np.exp(-a * (I - theta)))) \
         - (1 / (1 + np.exp(a * theta)))

def calcular_nullcline_E(params, n_pts=200):
    """Retorna pontos (rE, rI) onde drE/dt = 0 (nullcline de E)."""
    p = params
    rI_vals = np.linspace(0, 1, n_pts)
    rE_pts  = []

    for rI in rI_vals:
        # bissecção: encontra rE em [0,1] tal que -rE + F(wEE*rE - wEI*rI + Ie) = 0
        lo, hi = 0.0, 1.0
        for _ in range(50):
            mid = (lo + hi) / 2
            g   = -mid + F(p['wEE']*mid - p['wEI']*rI + p['Ie'], p['aE'], p['thE'])
            if g > 0: lo = mid
            else:     hi = mid
        rE_pts.append((lo + hi) / 2)

    return np.array(rE_pts), rI_vals
